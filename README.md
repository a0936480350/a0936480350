## 🎓 技術領域

### 後端
- **C#** — OOP、LINQ、async/await、泛型、委派/事件
- **ASP.NET Core** — MVC、Razor Pages、Web API、SignalR、Middleware、DI 容器
- **EF Core** — Code First、Migration、效能優化、N+1 處理
- **SQL** — Query 優化、Index 設計、Stored Procedure、Window Functions
- **ADO.NET** — 直接操作，理解 ORM 抽象層底下的運作

### 桌面開發
- **WPF** — XAML、Data Binding、LiveCharts、前後台分離設計
- **WinForms** — 事件驅動、GDI+、控制項自訂
- **硬體整合** — Bluetooth (32feet.NET)、Serial Port

### 前端
- **JavaScript** — ES6+、Promise、DOM、Fetch API
- **HTML/CSS** — Flexbox、Grid、RWD、動畫效果
- **遊戲開發** — Phaser.js 3（2D 遊戲引擎）
- **即時通訊** — SignalR Client（WebSocket）

### 架構思維
- **SOLID 原則** — 單一職責、開閉、里氏替換、介面隔離、依賴反轉
- **設計模式** — Repository、Strategy、Factory、Observer、Decorator
- **系統設計** — 認證機制（Session/JWT/OAuth）、快取策略、微服務 vs 單體
- **測試策略** — Mock vs 真實依賴
- **安全性** — SQL Injection 防禦、XSS、CSRF、密碼雜湊

### DevOps
- **Azure** — App Service、PostgreSQL Flexible Server、SQL Database
- **Git** — 分支策略、Rebase vs Merge、團隊協作
- **CI/CD** — GitHub Actions 基礎
